# 開発ロードマップ

各フェーズ末に Xcode でビルド・動作確認し、コミットする。
（技術スタックは当初の Flutter から、署名問題を回避するため SwiftUI + SQLite ネイティブへ移行）

| フェーズ | 内容 | 主な成果物 | 状態 |
| --- | --- | --- | --- |
| 0 | プロジェクト初期化 | XcodeGen 定義、SQLite基盤、.gitignore | ✅ |
| 1 | DB基盤 + 取引CRUD（MVP核） | Database, Models, Repositories, ホーム/取引編集画面 | ✅ |
| 2 | カテゴリ・口座・設定 | 各管理画面、振替、設定（通貨/テーマ/月開始日） | ✅ |
| 3 | 集計・グラフ | 月別推移・カテゴリ円グラフ（Swift Charts）、前月比 | ✅ |
| 4 | 予算管理 | 月次予算、消化率バー、超過アラート | ✅ |
| 5 | 定期取引・レポート・データ入出力 | 定期取引、カレンダー、CSV、バックアップ/復元 | ✅ |

## MVP の定義（フェーズ0〜1完了時）

- 支出・収入を記録でき、一覧で確認できる
- ホームで当月の収入・支出・収支差が見える
- デフォルトカテゴリが使える
- データが端末内SQLiteに永続化される

この時点で「使える家計簿」として動作確認し、以降フル機能へ拡張する。
