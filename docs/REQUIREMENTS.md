# 要件・機能一覧

家計簿管理アプリ（スマホ / SQLite / フル機能）の機能洗い出し。
優先度: ★★★ = MVP必須 / ★★ = フル機能で実装 / ★ = 将来拡張。

---

## 1. 取引（収支）管理 ★★★

家計簿の中核。日々の入出金を記録する。

- [ ] 支出の記録（金額・日付・カテゴリ・メモ・支払い方法）
- [ ] 収入の記録（金額・日付・カテゴリ・メモ）
- [ ] 振替の記録（口座間の移動。収支に計上しない）
- [ ] 取引の一覧表示（日付降順、日付ごとのグルーピング）
- [ ] 取引の編集・削除
- [ ] 取引の検索・フィルタ（期間・カテゴリ・金額・キーワード）
- [ ] 1件あたりの入力を数タップで完了できるUX

## 2. カテゴリ管理 ★★★

- [ ] デフォルトカテゴリの初期投入（食費・日用品・交通費・住居費・光熱費・娯楽・給与 等）
- [ ] カテゴリの追加・編集・削除（並び替え）
- [ ] アイコン・カラーの設定
- [ ] 親カテゴリ / サブカテゴリ（2階層）★★

## 3. 口座・支払い方法管理 ★★

- [ ] 口座（現金・銀行・電子マネー・クレジットカード）の登録
- [x] 口座ごとの残高表示（「口座」タブで一覧 + 総資産）
- [x] 仮想口座 / サブ口座（例: 銀行Aの中に「貯金用」「旅行貯金」）。取引時に選択でき、総額タブで親口座の合計と内訳を表示
- [ ] クレジットカードの締め日・引き落とし日管理 ★
- [x] 口座間の振替

## 4. 集計・ダッシュボード ★★★ / ★★

- [ ] ホーム画面に当月の収入・支出・収支差を表示 ★★★
- [ ] 月別の収支推移グラフ（折れ線 / 棒） ★★
- [ ] カテゴリ別支出の円グラフ ★★
- [ ] 期間指定での集計（日・週・月・年・カスタム） ★★
- [ ] 前月比・前年比の表示 ★

## 5. 予算管理 ★★

- [ ] 月次予算の設定（全体 / カテゴリ別）
- [ ] 予算消化率の表示（プログレスバー）
- [ ] 予算超過のアラート表示
- [ ] 予算の繰り越し設定 ★

## 6. 定期取引（繰り返し） ★★

- [ ] 定期収入・定期支出の登録（家賃・給与・サブスク等）
- [ ] 繰り返しルール（毎日 / 毎週 / 毎月 / 毎年）
- [ ] 自動計上 or リマインド通知
- [ ] 次回予定日の表示

## 7. レポート・分析 ★★

- [ ] 月次レポート（収支サマリ・カテゴリ内訳）
- [ ] 支出傾向の分析（増減の大きいカテゴリ）
- [ ] カレンダー表示（日別収支）

## 8. データ入出力 ★★ / ★

- [ ] CSVエクスポート ★★
- [ ] CSVインポート ★
- [ ] バックアップ / リストア（DBファイルの書き出し・読み込み）★★
- [ ] （将来）クラウド同期 ★

## 9. 設定・その他 ★★ / ★★★

- [ ] 通貨・言語設定（デフォルト: 円 / 日本語）★★★
- [ ] テーマ切替（ライト / ダーク）★★
- [ ] 月の開始日設定（給料日基準など）★★
- [ ] アプリロック（PIN / 生体認証）★
- [ ] 通知設定（入力リマインド・予算アラート）★

## MVP（最初のリリース範囲）

「フル機能」を目標としつつ、まず動く核を最短で作るための初期スコープ:

1. 取引のCRUD（支出・収入） — §1
2. カテゴリ管理（デフォルト投入 + 追加） — §2
3. ホームの当月サマリ + 取引一覧 — §4
4. 基本設定（通貨・テーマ） — §9

その後、予算管理 → グラフ → 定期取引 → レポート → データ入出力の順に拡張する（[ROADMAP.md](ROADMAP.md) 参照）。

## 非機能要件

- オフラインで全機能が動作する（ネットワーク不要）
- データは端末内SQLiteに保存（プライバシー重視）
- 起動・一覧表示は体感即時（インデックス設計で担保）
- 金額は整数（最小通貨単位）で保持し、浮動小数点誤差を避ける
